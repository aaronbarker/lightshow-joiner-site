Join follows the current table order of checked rows (sort a column or drag the handle to reorder). Only uncompressed V2 files with a matching pair (.fseq + audio) and the same step time can be concatenated, or turn on Convert 50ms → 20ms to expand 50ms frames onto a 20ms grid. Channel counts must match, or turn on Upgrade 48ch → 200ch to pad 48-channel frames to 200. Missing-pair and incompatible rows stay unchecked and locked. A successful join downloads a .zip with the combined .fseq and concatenated .mp3 (WAV tracks are converted first, in the browser). If audio join fails, you still get the FSEQ and an error message.

Companion to aaronbarker/lightshow-joiner. Default include set is 48 channels / 20 ms with a matching audio file. 50 ms shows stay skipped unless Convert 50ms → 20ms (experimental) is on. 200-channel / 20ms shows join the default set only when Upgrade 48ch → 200ch is on. Validation follows Tesla’s validator.py checks.
