Only uncompressed V2 files with a matching pair (.fseq + audio) and the same step time can be concatenated. Channel counts must match, or turn on Upgrade 48ch → 200ch to pad 48-channel frames to 200. Missing-pair and incompatible rows stay unchecked and locked. Audio join is coming next (ffmpeg.wasm). Download the FSEQ now and pair audio yourself, or use the Python CLI to concat MP3s.

Companion to aaronbarker/lightshow-joiner. Default include set is 48 channels / 20 ms with a matching audio file. 50 ms shows stay skipped (no step-time conversion). 200-channel / 20ms shows join the default set only when Upgrade 48ch → 200ch is on. Validation follows Tesla’s validator.py checks.
