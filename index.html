Join follows the current table order of checked rows (sort a column or drag the handle to reorder). Only uncompressed V2 files with a matching pair (.fseq + audio) and the same step time can be concatenated, or turn on Convert 50ms → 20ms to expand 50ms frames onto a 20ms grid. Channel counts must match, or turn on Upgrade 48ch → 200ch to pad 48-channel frames to 200. Each track is padded or trimmed so its audio length matches that show’s FSEQ duration (after those transforms), then concatenated — so later songs do not drift. An idle FSEQ tail past the audio is dropped instead of padding silence; an active tail keeps today’s pad and shows a warning. Optional Reset closures between shows injects one lights-off tail (and silence) after the last included show that still has Tesla command budget — not after every track. Missing-pair and incompatible rows stay unchecked and locked. After a join, each included row gets a Join verified or Join mismatch badge under the name — the output FSEQ is compared to that show’s frames (after the same 48→200 / 50→20 transforms; reset tails are skipped in the compare). A successful join downloads a .zip with the combined .fseq and concatenated .mp3 (WAV tracks are converted first, in the browser). If audio join fails, you still get the FSEQ and an error message.

About - This is a vibe coded AI project. I had a few Teslas at Halloween Trunk or Treat to do a lightshow and got really annoyed at having to re-setup everything every minute or two for short shows. I figured there must be a way to combined fseq files and AI said it could so this came to pass.

Disclaimer - This is far from perfect, but seems to do the job in my testing. No files are uploaded, everything happens on your browser. There is a potential for things getting out of sync the longer you go.

Default include set is 48 channels / 20 ms with a matching audio file. 50 ms shows stay skipped unless Convert 50ms → 20ms (experimental) is on. 200-channel / 20ms shows join the default set only when Upgrade 48ch → 200ch is on. Audio is padded or trimmed to each show’s FSEQ length before concat, except an idle FSEQ tail past the song is trimmed instead. Optional closure reset injects one defaults pose (trunk/charge closed, windows/mirrors open) at the latest point that still fits Tesla’s per-USB-show limits. Validation follows Tesla’s validator.py checks.
